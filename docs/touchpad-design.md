# 触控板模式设计（草案）

> 把 466×466 圆屏做成拇指操作的触控板，与现有「空中鼠 / 水平鼠」并存。

---

## 一、可行性

| 能力 | 现状 | 结论 |
|---|---|---|
| 电容触控 | CST820B，M5Unified 支持最多 5 点 | ✅ 单点可靠，多点待实测 |
| 圆屏有效区 | 直径 466 px，中心半径 ~200 px 可达 | ✅ 够用，边缘需留安全区 |
| BLE HID 报告 | 当前 4 字节（按键 + X/Y + 滚轮） | ⚠️ 需扩展（见第四节） |
| 振动反馈 | 马达已就绪 | ✅ 可用于点击/滚动确认 |
| 刷新率 | 主循环 1 ms，触摸读取受 I2C 限制 | ⚠️ 需实测采样率 |

**结论**：单点手势（拖动、点击、长按、边缘滑动）**完全可行**；双指滚动/缩放取决于 CST820B 是否上报第二点，需先测。

## 二、交互模型

### 尺寸划分

```
        ┌─────────────────┐
        │   状态栏 (y<80)  │  ← 不响应触摸，避免误触
        │   ┌───────────┐  │
        │   │           │  │
        │   │  触控区    │  │  半径 150 px 的圆
        │   │  (r=150)  │  │
        │   │           │  │
        │   └───────────┘  │
        │   手势提示 (y>380)│
        └─────────────────┘
```

- **触控区**：中心半径 150 px，拇指自然覆盖范围
- **禁用区**：上下各留 80 px，避免握持时误触
- **悬停指示**：触点画一个 12 px 的半透明圆点，实时跟随

### 指针移动

```
手指位移 → 指针位移

dx_cursor = (x_now - x_prev) × gain(speed)
```

**加速度曲线**（关键，否则慢速微调很难）：

| 手指速度 | gain | 效果 |
|---|---|---|
| < 1 px/ms（慢） | 0.6 | 精确定位 |
| 1–3 px/ms | 1.2 | 正常移动 |
| > 3 px/ms（快） | 2.0 | 快速跨屏 |

平滑：一阶低通 α = 0.4，抑制触控抖动。

## 三、手势表

| 手势 | 动作 | HID 输出 |
|---|---|---|
| 单指拖动 | 移动指针 | X/Y 相对位移 |
| **单指轻点** | 左键单击 | button 1 |
| **单指双击** | 左键双击 | 两次 button 1 |
| **单指长按 600ms** | 进入拖拽，抬手释放 | button 1 保持 |
| **单指上下滑（边缘区）** | 垂直滚动 | wheel |
| **双指上下滑** | 垂直滚动（更自然） | wheel |
| **双指左右滑** | 水平滚动 | AC Pan |
| **双指轻点** | 右键单击 | button 2 |
| **双指捏合/张开** | 缩放 | Ctrl + wheel |
| **左边缘右滑** | 后退 | button 4 |
| **右边缘左滑** | 前进 | button 5 |
| **三指上滑** | 切换窗口 | Alt + Tab（需键盘报告） |
| **三指下滑** | 显示桌面 | Win + D |

> 边缘手势需要把屏幕边缘 40 px 划为「边缘带」。圆屏下建议只做**左右边缘**，
> 上下边缘容易和滚动冲突。

## 四、HID 报告扩展

当前描述符只有 3 键 + 滚轮。上述手势需要：

### 必需（阶段一）

```c
// 5 键：左/右/中/后退/前进
Usage Maximum (Button 5), Report Count (5)

// 滚轮 + AC Pan（水平滚动）
Usage (Wheel), Usage (Consumer: AC Pan)
Logical Min (-127), Logical Max (127)
Report Size (8), Report Count (4)   // buttons + X + Y + wheel + pan
```

报告从 4 字节变 5 字节。**注意**：AC Pan 必须写在同一个 Physical Collection
里、切到 Consumer page，Windows 才认作水平滚轮。

### 可选（阶段二）

- **Consumer 报告**（媒体键、音量）：独立 Report ID
- **键盘报告**（Alt+Tab、Win 组合键）：独立 Report ID + 修饰键字节

每加一个 Report ID，GATT 特征数增加。当前已经因为 HID 服务注册失败在排查，
**建议阶段一只加 5 键 + AC Pan，不加新 Report ID**。

## 五、硬件限制与对策

| 限制 | 影响 | 对策 |
|---|---|---|
| 触摸采样率未知（I2C，可能 20–60 Hz） | 快速滑动丢点 | 用插值补点；实测后决定是否需要提高 I2C 频率 |
| 圆屏，四角不可达 | 手势区域受限 | 只用中心圆 + 左右边缘带 |
| 握持时手掌接触 | 误触 | 顶部/底部 80 px 禁用；接触面积过大时忽略 |
| 单点可能被识别为拖动起点 | 点击判定 | 抬手时若位移 < 8 px 且时长 < 200 ms 判为点击 |
| 多点支持未知 | 双指手势 | **先实测 `M5.Touch.getCount()`**，不支持就退回单指边缘滚动 |

## 六、与现有模式的关系

建议做成**第三种模式**，而不是叠加层：

| 模式 | 切换方式 |
|---|---|
| 空中鼠（陀螺仪） | A+B 长按循环 |
| 水平鼠（加速度计） | A+B 长按循环 |
| **触控板** | A+B 长按循环 |

理由：
- 三者输入源完全不同，叠加会让行为不可预测
- 触控板模式下 IMU 应关闭，省电
- 屏幕在触控板模式要显示触点、手势提示，布局与现有两种不同

模式切换仍是 **A+B 长按**，循环顺序：空中鼠 → 水平鼠 → 触控板 → 空中鼠。

## 七、触觉反馈

| 事件 | 振动 |
|---|---|
| 点击 | 1 短振 40 ms |
| 双击第二下 | 1 短振 40 ms |
| 长按进入拖拽 | 1 长振 120 ms |
| 边缘手势触发 | 2 短振 |
| 滚动每 3 格 | 1 极短振 15 ms（可选，避免烦人） |

## 八、风险

1. **触摸采样率不足** → 指针发飘。需先实测，若低于 30 Hz 要考虑不用触控板做指针，只做滚动/手势。
2. **多指支持** → 决定双指手势能否实现。
3. **HID 描述符变更** → 主机需要重新配对（Windows 会缓存 HID 报告描述符）。
4. **当前 BLE 链路未通** → 一切功能的前提。

## 九、阶段计划

### 阶段 0（前置）
修好 HID 服务注册问题，确认设备能被 Windows 识别为鼠标。

### 阶段 1（最小可用）
- 单指拖动移动指针
- 轻点 = 左键，双击 = 双击
- 长按 = 拖拽
- 边缘上下滑 = 滚轮
- 屏幕显示触点和手势提示

### 阶段 2
- 双指滚动（若硬件支持）
- 左右边缘 = 后退/前进（需 5 键描述符）

### 阶段 3
- 捏合缩放（Ctrl+滚轮）
- 三指手势（需键盘报告）
